# Park Cycling Project

A personal website about cycling in the park, featuring an introduction to park riding, a professional resume, and a guide to choosing trails.

## Pages

- **Home** - Introduction to park cycling and its benefits
- **Resume** - Professional experience and skills
- **Trails** - Guide to different trail types and preparation checklist

## Media

The project includes photography and video assets demonstrating various aspects of park cycling.

## Getting Started

Open `index.html` in your web browser to view the website.
